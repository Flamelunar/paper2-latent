# 目标判定与公开输出修复实验计划

日期：2026-10-06。旧 GPU 0 实验已暂停，训练不重跑，不恢复旧进程，不操作 GPU 4。

## 固定数据和模型

所有正式测试使用 test_selection_192.json 的192个无前置对话场景，五轮交互。pilot 使用固定 SHA256 排序前20条，不依据分数选样本。Qwen2.5-7B-Instruct为基础劝说模型；Our复用 checkpoint-001800，包含语言模型LoRA、隐式状态和RL策略模块。模拟对象为本地合并 Qwen3.5-9B-persuadee；Judge为Selene-1-Mini-Llama-3.1-8B。模型使用BF16。

## 修改内容

1. Zero-shot仅输入背景和已生成公开历史；不输入目标、标注心理、策略或golden。
2. MA2P仍为Perception → World Model → Persuader、K=0；显式目标供MA2P使用，内部分析由模型推断；严格结构化字段，不再默默接受空分析或默认策略。
3. 三方法公开输出共同截断后续角色标签和续写，保存真正raw输出。Our同一次生成心理分析、策略与话语三字段；心理与策略存档，只有话语进入模拟对象、历史、隐式状态反馈和Judge。此实验是分析＋话语推理变体，不代表训练了新checkpoint。
4. Our提示词保留完整公共历史，最多6144 tokens，超过预算报错。相对于旧推理1536预算，这是另一个明确的实验改动；本实验不能独立归因于单一修复。
5. Success先摘录当前被劝说者原话，再判断none/engagement/conditional/accepted；success只能true或false，accepted与true严格一致。考虑、了解、试驾等中间步骤不能自动算购买/采用目标成功。任何五轮中的一轮accepted计成功，失败轮数计5。
6. Win@1对比第一句与golden第一句；Win-Full对比所有已记录对话，不补造golden缺失轮次。使用v3独立评估后比较提示词，追加精确目标要求。A/B和B/A作为位置偏差控制，非独立样本；胜1、平0.5、负0取均值，额外报告换序冲突与平局比例。
7. 各方法固定相同采样参数和场景seed。不使用Judge筛选生成。仅格式错误可重试，最多3次，保留失败raw。

## 执行顺序与验收

先静态编译、数据/checkpoint合同校验、公开边界及布尔解析验证，再GPU0运行三方法20条重新生成；旧三个方法同样20条保存输出用新Judge复评。保存comparison_20.md/json后，同版本续跑三方法192条，保存comparison_192.md/json。不能因为Our未领先而更换样本或修改Judge。两个阶段源码合同固定，192复用已生成的20条。

每条生成/判分即时落盘；supervisor_state.json、generation_progress.json与evaluation_progress.json可查看阶段。程序报错则停止后续阶段，保留断点；修复源码后须建立新版本合同或明确迁移，不能静默混算。

GPU0保留旧暂停训练的显存；生成进程上限38GiB、额外容量预检，评估单独加载Judge，上限30GiB。预计时间须根据实际每场景耗时估算，尚无实测速度时不报确定完成时刻。20条只用于先看变化，不足以证明优势；192条报告才是正式结果。旧主表和旧日志保留，结果先写独立实验目录，验证完成后再明确更新表格。

## 2026-10-06 加速修订：每批两个场景

用户授权使用场景批处理。不同场景共享模型权重，同一场景内各轮仍保持先劝说、再回应的顺序。每个场景拥有独立历史、MA2P计划、ECLP状态与逐调用随机生成器。左侧padding通过attention mask隔离，隐式连续前缀在同一次解码中批处理；模型权重、BF16、温度0.95/top-p0.7/top-k50、512 tokens上限、五轮及Judge提示词保持原设置。

为保留完成结果，冻结串行任务并备份JSONL后切换至独立 target_grounded_v4_batch2 目录。已经保存的串行记录保留原来源行hash及合同hash，复制到新实验时明确标记 batch_size_requested=1；新记录为2。不同batch下浮点舍入和采样实现可能导致输出文本不同，不能宣称逐token完全相同或评估分数不变。若发生OOM，只对同一批原请求、原seed退回单条运行，不缩短历史或降精度。

公开角色边界改用各行独立的尾部token解码检测，避免每个新角色姓名触发StopStringCriteria全词表预处理；与保存时的边界截断规则一致。最终速度用首批完整五轮耗时实测，不预先承诺翻倍。
